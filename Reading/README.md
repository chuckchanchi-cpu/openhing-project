# Reading — 每日一篇（Daily Reading・筆答選擇題）

> 來源：Justan Edu Discord #general（chuck 每日分享文章，一中一英）｜設定：2026-11-23（修訂）
> 用途：**S1 面試筆答閱讀理解**（paper 上揀 A/B/C/D），同 App 內容倉。
> ⚠️ 口試（oral）係另一個 section，唔喺呢個格式範圍。

## 每日流程

1. chuck 分享文章（相片或文字）
2. **OCR／逐字記錄原文**（唔可以改寫、唔可以節錄，題目要 traceable）
3. 出 **8 題四選一選擇題**（每題 4 個選項，答案唯一）
4. 每題附：**正確答案**、**文中依據（引原文）**、**💡解題技巧**、**⚠️陷阱**
5. 記錄入 `Reading/YYYY-MM-DD_閱讀_中文_<標題>.md` 同 `Reading/YYYY-MM-DD_閱讀_英文_<Title>.md`

## 題型分配（每篇 8 題）

| # | 題型 | 考咩 |
|---|---|---|
| 1 | 主旨 | 全文主要講咩 |
| 2 | 細節 | 文中明確寫出嘅事實 |
| 3 | 細節 | 另一個明確事實（數字／人物／地點） |
| 4 | 推論 | 文中冇直講，要推出來 |
| 5 | 詞義 | 某詞在文中嘅意思 |
| 6 | 逆向（NOT / 除外） | 邊項文中冇提 |
| 7 | 因果／目的 | 為甚麼／為了甚麼 |
| 8 | 作者態度／深層意思 | 語氣、教訓、言外之意 |

面試卷通常 8–12 題、15–20 分鐘。8 題係一份「啱啱好」嘅每日練習。

## 記錄檔格式

```markdown
# YYYY-MM-DD 每日一篇・中文/英文：<標題>

> 來源：（出處／chuck 分享）｜記錄：YYYY-MM-DD｜適用：小六・S1 面試｜篇幅：N 字／N 詞

## 文章
（原文，逐字記錄，保留分段）

## 閱讀理解（8 題・四選一）

### Q1（主旨）
題目…
- A. …
- B. …
- C. …
- D. …

**答案：** B
**文中依據：** 「（引原文）」
💡 技巧：…
⚠️ 陷阱：…
```

## 品質規則（必守）

1. **答案必須喺文中搵到支持** — 每題要有「文中依據」引原文，冇就唔准入庫
2. **干擾項要似** — 同範疇、字面接近，唔可以一眼排除；但必須錯得清楚
3. **唔可以考文章以外嘅常識**（除非題目明講「根據常識」）
4. **逆向題**（NOT／除外）要逐項核對原文，三個真、一個假
5. **數字題**要對準原文，唔可以靠印象
6. **唔可以有兩個都對嘅選項**（出完自己再核一次）

## App 對接

內容驅動：每日 app 直接讀本資料夾嘅 `.md`，每日更新唔使改 code。
`zh-reading-trainer` / `en-reading-trainer` 已有題庫引擎，優先擴充佢哋，唔開新 app。
