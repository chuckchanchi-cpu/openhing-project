# Reading — 每日一篇（Daily Reading）

> 來源：Justan Edu Discord #general（chuck 每日分享文章，一中一英）｜設定：2026-11-23
> 目的：面試閱讀理解訓練（中文＋英文口頭作答），同 App 內容倉。

## 每日流程

1. chuck 分享文章（相片或文字）
2. 記錄入 repo：`Reading/YYYY-MM-DD_閱讀_中文_<標題>.md` 同 `Reading/YYYY-MM-DD_閱讀_英文_<Title>.md`
3. 每篇出 **5 題閱讀理解**（面試口答式）：
   - 題型分配：主旨 1、細節 1、推論 1、詞義 1、開放表達 1
   - 每題附**模範答案**（完整句＋because/引證展開）＋💡技巧＋⚠️陷阱
4. 每份 PDF／App 用同一格式（同 面試口答訓練卷一 款式）

## 記錄檔格式

```markdown
# YYYY-MM-DD 每日一篇・中文/英文：<標題>

> 來源：（出處／chuck 分享）｜記錄：YYYY-MM-DD｜適用：小六・S1 面試

## 文章
（原文，逐字記錄）

## 閱讀理解 5 題
### Q1（主旨）
題目...
**模範答案：** ...
💡 ... ⚠️ ...
```

## App 對接

內容驅動：daily-reading app 直接讀本資料夾嘅 .md，每日更新唔使改 code。
