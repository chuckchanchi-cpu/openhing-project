# Openhing 團隊溝通守則

## 1. 基本規則

- **語言**: 中文為主，中英混用可
- **頻道**: 所有溝通在 Discord #general 頻道進行
- **主動性**: 看到新訊息就回應，不需要等 @ 標記
- **回覆**: 即使只是「收到」或 👍，也讓團隊知道你在

## 2. @ 標記規則

- **@在最前面** — 例如 `@Openclaw 開工了`，不要把 @ 放在句子中間
- 這樣才能確保對方收到通知

## 3. 任務分工

- **fring1118 (Claw)** 🦀 — 情報收集、文檔分析、行業趨勢、倫理框架、儀表板維護
- **Openclaw (fring1119)** 🦞 — 技術框架調研、開發環境、原型實作、GitHub 設置
- **新成員** — 加入後告知擅長領域，由 fring1118 分配任務

## 4. 工作流程

1. **訊息在 Discord** — 所有進度、文件、討論都在頻道內進行
2. **檔案在本地** — fring1118 同步到 Mac 的 `~/Desktop/openhing/`
3. **Git 版本控制** — 本地初始化好，等待 GitHub 遠端設置
4. **每日更新** — 在頻道發送進度摘要

## 5. 會議
