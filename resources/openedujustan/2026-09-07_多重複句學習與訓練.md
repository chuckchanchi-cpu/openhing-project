## 📖 第一部分：學習 — 甚麼是複句和多重複句？

- **複句**：由兩個或以上「分句」組成的句子，分句之間用**關聯詞語**連接。
- **多重複句**：句子包含兩個或以上**層次**的關係。

### 常見關聯詞語

| 關係 | 關聯詞語 |
|---|---|
| 並列 | 一邊……一邊……、既……又…… |
| 遞進 | 不但……而且……、甚至 |
| 轉折 | 雖然……但是……、可是、然而 |
| 因果 | 因為……所以……、既然……就…… |
| 條件 | 只要……就……、只有……才…… |
| 假設 | 如果……就……、即使……也…… |
| 選擇 | 與其……不如……、寧可……也不…… |

### 課文例句分析

**例一：**「得到最大的當然理想，把眼前一棵飽滿的麥穗拿在手中，才是最實在的。」

- 這是**轉折關係**的複句，可以加上關聯詞語：
  「**雖然**得到最大的當然理想，**但是**把眼前一棵飽滿的麥穗拿在手中，才是最實在的。」
- 意思：雖然追求理想是好事，但把握眼前實際的機會更加重要。

**例二：**「我才走進麥田，發現一棵很大的麥穗，我還想往前找找看，所以放棄了。」

- 第一層：「我才走進麥田，發現一棵很大的麥穗」（承接上文）
- 第二層：「我還想往前找找看」（原因），「所以放棄了」（結果）
- 這是**因果關係**的多重複句：因為還想往前找找看，所以放棄了眼前的麥穗。

### 練習二：判斷複句的關係（轉折・因果・條件・選擇・遞進）

1. 因為他猶豫不決，所以錯過了採摘的時機。（＿＿＿＿＿＿）

2. 雖然理想很美好，但是現實更重要。（＿＿＿＿＿＿）

3. 只要把握眼前，就不會後悔。（＿＿＿＿＿＿）

4. 與其追求最大的，不如珍惜已有的。（＿＿＿＿＿＿）

5. 他不但沒有收穫，而且浪費了時間。（＿＿＿＿＿＿）

## 答案（家長用）

**練習一：**
1. 雖然……但是……　2. 因為……所以……　3. 只要……就……　4. 與其……不如……　5. 不但……而且……

**練習二：** 1. 因果　2. 轉折　3. 條件　4. 選擇　5. 遞進

**練習三：**
1. 雖然這棵麥穗不是最大的，但是它是一棵飽滿的麥穗。
2. 因為他東張西望，總在比較，所以一再錯失良機。
3. 只要你把握眼前的機會，你就不會後悔。

**練習四：** 開放題（示例）
1. 因為「我」認為前面會有更大的麥穗，想繼續向前找。
2. 「我」是一個猶豫不決、不懂把握眼前機會的人。
3. 開放作答，言之成理即可。
