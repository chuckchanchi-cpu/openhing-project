## 一、溫習區

### 1. 小數除以整數
- 小數除以整數，可以當作**整數除法**計算，商的小數點要與被除數的小數點**對齊**。
- 例：6.2 ÷ 2 = 3.1

```
  3.1
2 ) 6.2
```

- 除到最後如有餘數，可以在被除數後面**補 0** 繼續除。
- 例：48 ÷ 5 = 9.6

```
  9.6
5 ) 48.0
```

### 2. 分數化小數
- 分數化小數：用**分子 ÷ 分母**。
- 例：1/4 = 1 ÷ 4 = 0.25
- 例：3/4 = 3 ÷ 4 = 0.75

**常用分數與小數對照：**

| 分數 | 小數 |
|---|---|
| 1/4 | 0.25 |
| 2/4 = 1/2 | 0.5 |
| 3/4 | 0.75 |
| 1/5 | 0.2 |
| 2/5 | 0.4 |
| 3/5 | 0.6 |
| 4/5 | 0.8 |
