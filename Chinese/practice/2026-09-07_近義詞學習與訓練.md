## 📖 第一部分：學習 — 甚麼是近義詞？

**近義詞**就是**意思相近**的詞語。它們的意思相似，但在用法上有些**細微的分別**。

分辨近義詞，可以從以下 **5 個方面**入手：

1. **詞義輕重** — 哪一個語氣較重？（例：喜歡 < 喜愛 < 熱愛）
2. **範圍大小** — 哪一個範圍較大？（例：「果實」的範圍比「蘋果」大）
3. **感情色彩** — 褒義 / 貶義 / 中性？（例：頑強（褒義）vs 固執（貶義））
4. **搭配習慣** — 哪些字詞習慣與它搭配？（例：「把握時機」「錯失良機」）
5. **運用場合** — 口語還是書面？正式還是日常？

### 課文出現的近義詞組

| 詞語 | 近義詞 | 細微分別 |
|---|---|---|
| 機會 | 時機・良機 | 「機會」最普遍；「時機」強調時間是否恰當；「良機」指良好的機會，較書面 |
| 寬廣（廣大） | 廣闊 | 都形容範圍大；「寬廣」常用於抽象事物（心胸寬廣），「廣闊」常用於具體地方（廣闊的草原） |
| 捨棄 | 放棄 | 「捨棄」是主動丟掉、不要（書面）；「放棄」較口語常用 |
| 躊躇 | 猶豫・遲疑 | 都指拿不定主意；「躊躇」較書面，「猶豫」較口語 |
| 宛如 | 好像・彷彿 | 「宛如」是書面語，較正式；「好像」口語常用 |
| 東張西望 | 左顧右盼 | 都指四處張望；「東張西望」略帶貶義（不專心） |
