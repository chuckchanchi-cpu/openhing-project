# 中文練習卷 — 單元三：智慧的種子（第7課）

## 📋 練習內容

### 一、課文問題：《要挑最大的》
1. 學生都用「心」地挑選麥穗，為甚麼到最後卻沒有人摘到最大的麥穗？
2. 蘇格拉底讓學生摘麥穗，目的是甚麼？

### 二、分析比喻句（明喻 vs 借喻）
1. 在好心人的幫助下，她逃出了虎口，找回自己的爸媽。 → **借喻**
2. 馬路如虎口，大家要小心過馬路。 → **明喻**
3. 他們雖然停止了爭吵，但空氣中的火藥味還是很濃。 → **借喻**
4. 他煩躁得很，像吃了火藥，我們暫時不要招惹他。 → **明喻**
5. 經過警方的盤問，他的狐狸尾巴終於露出來了。 → **借喻**
6. 他狡猾得很，像一隻狐狸，你不要相信他。 → **明喻**

### 三、標點符號練習
爸爸問明心想買什麼玩具，她卻拿不定主意。結結巴巴地說：「我想要爸爸和藹地說：『你自己挑選吧！』看了大半天，明心終於挑選了她心愛的寶貝—娃娃玩具屋。」

### 四、關聯詞填空
- 無論…都… / 只要…就… / 除非…否則… / 要是…那麼…
- 倘若…就… / 儘管…可是… / 不是…而是…

1. （儘管）你的幫助這麼微薄，（可是）他卻感激不已。
2. （無論）是音樂還是詩歌，（都）可以把美的意境融合在一起。
3. 秋天（不是）人生易老的象徵，（而是）碩果豐收的標誌。
4. （只要）我們珍惜時間，（就）能學到更多知識。
5. （除非）停止屠殺鱷魚，（否則）牠們將絕跡於世上。

## 💡 重點提示

### 明喻 vs 借喻
| 類型 | 結構 | 例子 |
|------|------|------|
| **明喻** | A 像 B | 馬路如虎口、像吃了火藥 |
| **借喻** | 直接用 B 代替 A | 逃出虎口、火藥味濃、狐狸尾巴 |

### 關聯詞用法
| 關聯詞 | 用法 | 例句 |
|--------|------|------|
| 儘管…可是… | 轉折 | 儘管下雨，可是我們還是去了 |
| 無論…都… | 條件 | 無論怎麼努力，都會有收穫 |
| 不是…而是… | 選擇 | 這不是失敗，而是機會 |
| 只要…就… | 充分條件 | 只要你努力，就會成功 |
| 除非…否則… | 必要條件 | 除非你道歉，否則我不理你 |

### 近義詞辨析技巧
1. **乾旱**（A）：長期缺雨（天候）
2. **乾澀**（B）：口舌乾澀（身體感受）
3. **乾涸**（C）：水乾了（具體物體）
4. **乾燥**（D）：沒有水分（一般狀態）
