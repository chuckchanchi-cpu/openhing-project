## 💡 記憶技巧總結

### 技巧1：詞尾分類法
| 詞尾 | 代表意思 | 例子 |
|------|----------|------|
| **-er / -or** | 做某事的人 | teacher, writer, actor, director |
| **-ist** | 從事某種專業的人 | dentist, violinist, engineer |
| **-man / -woman** | 男性/女性工作者 | policeman, fireman, saleswoman |
| **-ist / -ian** | 特定領域專家 | astronaut, artist |

### 技巧2：動詞+後綴法
- **動詞 + -er/-or** = 做這個動作的人
  - paint → painter（畫畫的人）
  - write → writer（寫字的人）
  - edit → editor（編輯的人）
  - direct → director（導演的人）

### 技巧3：名詞組合法
- **A + B person** = 做A事情的人
  - charity worker（慈善工作者）
  - flight attendant（航班侍應生）
  - tour guide（旅遊導覽者）

### 技巧4：特殊拼寫記憶
- **chef**（廚師）→ 不是 cook，是法語原詞
- **vet**（獸醫）→ veterinary doctor 的簡寫
- **actor/actress** → actor通用，actress特指女性
