## 📝 題目與正確答案

### Part 1：動詞三式表（base → past → future）

| Base | Past | Future |
|------|------|--------|
| go | went | will go |
| take | took | will take |
| buy | bought | will buy |
| read | read | will read |
| draw | **drew** | will draw |
| make | **made** | will make |
| look | looked | will look |
| stop | **stopped** | will stop |
| have | had | will have |
| bring | brought | will bring |
| think | thought | will think |

- ✅ Future 欄全部 = **will + base form**
- 💡 分析：
  - **不規則變化**要死記：go-went、take-took、buy-bought、draw-**drew**、make-**made**、have-had、bring-brought、think-thought
  - **read-read**：三式同形但發音唔同（past 讀 /red/）
  - **stop-stopped**：短母音 + 單輔音尾 → 雙寫輔音再加 -ed

## 🔑 加分要點（訓練重點）
1. **will + base form**：will 後面嘅動詞永遠用原形，唔好畀主詞或時態干擾
2. **不規則動詞**：draw-drew、make-made 呢類易漏背；三式表逐個默書
3. **-ed 拼寫規則**：stop → stopped（雙寫）、look → looked（直接加）
4. **同形動詞**：read-read-read，靠讀音 /riːd/ vs /red/ 分辨
5. **填充檢查**：填完朗讀一次，will + base 讀落順唔順
