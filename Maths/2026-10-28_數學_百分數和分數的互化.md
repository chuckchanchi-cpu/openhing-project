# 數學 — 單元五：百分數和分數的互化（p.23-25）

> 來源：Justan Edu Discord #general（2026-10-28 上載工作紙照片）｜記錄：2026-10-28｜適用：小六
> 主題：圖形百分數/分數表示、百分數↔分數互化、比較陰影大小、百分數應用

## 📝 題目與正確答案

### 一、圖形表示（①-④：最簡分數＋百分數）
| # | 圖 | 最簡分數 | 百分數 |
|---|-----|---------|--------|
| ① | 15 格着 7 格 | **7/15** | **46⅔%**（≈46.7%） |
| ② | 八角形 8 份着 1 份 | **1/8** | **12½%** |
| ③ | 4 格着 3 格 | **3/4** | **75%** |
| ④ | 12 份着 5 份 | **5/12** | **41⅔%**（≈41.7%） |

### 二、⑤ 圈出同水桶數值相同嘅答案
- 桶 **3½** → **350%**（3.5 = 350%；3.5%、320% 都唔啱）
- 桶 **46%** → **23/50**（46/100 = 23/50）
- 桶 **1 7/15** → **146⅔%**（22/15 ≈ 1.4667 = 146⅔%）

### 三、⑥ 百分數 → 最簡分數
| 百分數 | 最簡分數 |
|--------|---------|
| 8% | **2/25** |
| 16.5% | **33/200** |
| 5⅛% | **41/800** |
| 706% | **353/50**（= 7 3/50） |
| 0.2% | **1/500** |
| 3¾% | **3/80** |

### 四、⑦ 分數 → 百分數
| 分數 | 百分數 |
|------|--------|
| 9/20 | **45%** |
| 56/200 | **28%** |
| 5/16 | **31¼%**（31.25%） |
| 125/200 | **62½%**（62.5%） |
| 1 3/25 | **112%** |
| 2 5/9 | **≈255.6%**（255⅕%）⚠️ 循環小數取約值 |

### 五、⑧ 陰影大於全圖 40% 的圖（P/Q/R/S）
- P（菱形一半 = 50%）、R（12 格着 7 ≈ 58%）、S（半圓 = 50%）> 40%；Q（3 格着 1 = 33⅓%）< 40%
- **答案：P、R、S** ✅

### 六、⑨ 書法展覽
- 楷書作品佔全部作品的 44% →（a）最簡分數 **11/25**
- 行書和草書各佔 7/25（= 28%）→（b）共佔 **56%**

## 🎯 題型要點
1. **互化技巧**：分數→百分數（除開 ×100）；百分數→分數（÷100 化最簡）；帶分數先化假分數
2. **循環小數**：5/12 = 41.666… → 41⅔%（用分數百分數最穩陣）
3. **比較大小**：全部化同一形式（建議分數或百分數）先比
4. ⚠️ 常見錯誤：706% 呢類大過 100% 要化帶分數/假分數、½/⅔ 嘅分數百分數寫漏、16.5% 化分數唔約簡
