## 一、混合數的加法

### 公式
```
a b/c + d e/f = (a + d) + (b/c + e/f)
```

### 例題 1
```
2⅔ + 1⅖ = ?
= (2 + 1) + (2/3 + 2/5)
= 3 + (10/15 + 6/15)
= 3 + 16/15
= 3 + 1 + 1/15
= 4⅔
```

### 例題 2
```
3¼ + 2⅔ = ?
= (3 + 2) + (1/4 + 2/3)
= 5 + (3/12 + 8/12)
= 5 + 11/12
= 5⅚
```

---

## 二、混合數的減法

### 公式
```
a b/c - d e/f = (a - d) + (b/c - e/f)
```

### 例題 3
```
4½ - 1⅓ = ?
= (4 - 1) + (1/2 - 1/3)
= 3 + (3/6 - 2/6)
= 3 + 1/6
= 3⅙
```

### 例題 4
```
5⅔ - 2¾ = ?
= (5 - 2) + (2/3 - 3/4)
= 3 + (8/12 - 9/12)
= 3 - 1/12
= 2 + (12/12 - 1/12)
= 2 + 11/12
= 2⅚
```
