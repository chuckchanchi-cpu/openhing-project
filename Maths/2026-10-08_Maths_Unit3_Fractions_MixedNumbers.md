# Unit 3 - Fractions 分數
## 加減混合數 Mixed Numbers

### 一、認識混合數 Mixed Numbers

混合數是由整數和分數組成的數，例如：
- 2½ (二又二分之一)
- 3¼ (三又四分之一)

### 二、混合數加法

**計算步驟：**
1. 將分數部分通分
2. 將分子相加
3. 如分子大於分母，需化為帶分數
4. 將整數部分和分數部分相加

#### 例題：

**例題 1：** 2⅔ + 1⅖ = ?

**解答：**
```
2⅔ + 1⅖
= (2 + 1) + (2/3 + 2/5)
= 3 + (10/15 + 6/15)
= 3 + 16/15
= 3 + 1 + 1/15
= 4⅔
```

**例題 2：** 3¼ + 2⅔ = ?

**解答：**
```
3¼ + 2⅔
= (3 + 2) + (1/4 + 2/3)
= 5 + (3/12 + 8/12)
= 5 + 11/12
= 5⅚
```

#### 練習題：

1. 2⅔ + 1⅖ = ?
2. 3¼ + 2⅔ = ?
3. 1½ + 2⅓ = ?
4. 4⅕ + 2⅖ = ?
5. 2¾ + 1⅙ = ?

---

### 三、混合數減法

**計算步驟：**
1. 將分數部分通分
2. 如被減數的分數部分小於減數的分數部分，需向整數部分借 1
3. 將分子相減
4. 將整數部分和分數部分合併

#### 例題：

**例題 1：** 4½ - 1⅓ = ?

**解答：**
```
4½ - 1⅓
= (4 - 1) + (1/2 - 1/3)
= 3 + (3/6 - 2/6)
= 3 + 1/6
= 3⅙
```

**例題 2：** 5⅔ - 2¾ = ?

**解答：**
```
5⅔ - 2¾
= (5 - 2) + (2/3 - 3/4)
= 3 + (8/12 - 9/12)
= 3 - 1/12
= 2 + (12/12 - 1/12)
= 2 + 11/12
= 2⅚
```

#### 練習題：

1. 4½ - 1⅓ = ?
2. 5⅔ - 2¾ = ?
3. 3½ - 1⅔ = ?
4. 6⅕ - 2⅖ = ?
5. 5⅚ - 2⅚ = ?

---

### 四、思考題

**問題 1：** 小明有 3½ 公斤的蘋果，給了朋友 1¼ 公斤，还剩多少公斤？

**解答：**
```
3½ - 1¼ = 3 - 1 + (1/2 - 1/4)
       = 2 + (2/4 - 1/4)
       = 2 + 1/4
       = 2¼ (公斤)
```

**問題 2：** 一條繩子長 5⅔ 米，剪去 2¾ 米後，剩下多少米？

**解答：**
```
5⅔ - 2¾ = 5 - 2 + (2/3 - 3/4)
         = 3 + (8/12 - 9/12)
         = 3 - 1/12
         = 2 + (12/12 - 1/12)
         = 2 + 11/12
         = 2⅚ (米)
```

---

### 五、重點提示

1. **通分：** 將分數化為同分母，才能進行加運算
2. **約分：** 結果需化為最簡分數
3. **借位：** 當減數的分數大於被減數的分數時，需向整數部分借 1
4. **檢查：** 將答案代入原式驗算

### 六、答案

#### 加法答案：
1. 2⅔ + 1⅖ = 4⅔
2. 3¼ + 2⅔ = 5⅚
3. 1½ + 2⅓ = 3⅚
4. 4⅕ + 2⅖ = 6⅗
5. 2¾ + 1⅙ = 3⅔

#### 減法答案：
1. 4½ - 1⅓ = 3⅙
2. 5⅔ - 2¾ = 2⅚
3. 3½ - 1⅔ = 1⅚
4. 6⅕ - 2⅖ = 3⅘
5. 5⅚ - 2⅚ = 3
