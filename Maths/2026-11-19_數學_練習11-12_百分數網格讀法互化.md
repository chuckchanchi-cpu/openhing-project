## 練習11（p.7）— 百分數認識

### 網格圖（100 格 = 100%）
1. 左圖着色 **42** 格 = **42%**（⚠️ 逐行數格，唔好眼估）
2. 右圖着色（中間藍色＋四角）**20** 格 = **20%**
3. 依指示塗色：着色部分佔全圖 **25%**（塗 25 格）
4. 依指示塗色：着色部分佔全圖 **60%**（塗 60 格）

### 百分數表示與讀法
5. 39% = **39/100**；39% 讀作「**百分之三十九**」
6. 4.07% = **4.07/100**；讀作「**百分之四點零七**」
7. 155% = **155/100**；讀作「**百分之一百五十五**」（⚠️ 唔係「百分之一百五十五」以外嘅讀法）
- **讀法規則**：% 前嘅數字照讀，前面加「百分之」；4.07% 讀「百分之四點零七」

### 百分比應用（100 張手工紙：紅 30%、黃 27%、藍 43%）
8. (a) 黃色手工紙有 **27** 張（100×27%）
   (b) 紅黃藍共佔 **100**%
   (c) 紫色手工紙佔 **0**%（⚠️ 三色已達 100%，其他顏色 = 0）

## 練習12（p.14）— 最簡分數與百分數互化

### 圖形 → 最簡分數 + 百分數
1. 綠色 4/5 = **80%**
2. 梯形三角 **1/5 = 20%**（⚠️ 手寫 33⅓% 係錯）
3. 圓形 **5/8 = 62½%**（62.5%）
4. 十字形 **1/2 = 50%**

### 百分數 → 最簡分數（⚠️ 先變假分數/小數再約簡）
5. 35% = **7/20**
6. 256% = 256/100 = **64/25**（假分數）
7. 13.2% = 132/1000 = **33/250**
8. 30.5% = 305/1000 = **61/200**
9. 7½% = 7.5/100 = 75/1000 = **3/40**
10. 8 2/11% = (90/11)÷100 = **9/110**

### 分數 → 百分數（⚠️ 除不盡用分數百分數）
11. 1/5 = **20%**
12. 7/8 = **87.5%**
13. 3/7 = **42 6/7%**（42⅚%）— 除不盡 → 分數百分數
14. 1¾ = **175%**
15. 2 1/16 = **206¼%**（206.25%）
16. 2⅔ = **266⅔%**（266 2/3%）

## ⚠️ 必考陷阱
1. **讀法**：百分數讀「百分之X」，小數照讀（4.07% → 百分之四點零七）
2. **假/帶百分數**（>100%）：256% = 64/25、155% = 31/20
3. **除不盡**→ 用**分數百分數**（3/7 = 42 6/7%），唔好四捨五入
4. **化最簡**：13.2% 要先 ×10 變 132/1000 再約簡
5. **總和檢查**：三色已 100% → 其他顏色 0%
