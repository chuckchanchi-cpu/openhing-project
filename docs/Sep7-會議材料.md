## 一、項目一句話總結

**Openhing = Ethical AI Research Assistant**：一個以人為本（增強而非取代人類）嘅多智能體研究系統，由 CrewAI 驅動 — 輸入任何研究主題，系統自動完成「真實網上搜索 → 多角度分析 → 完整文章撰寫」，全程唔使人手干預。

**緣起：** 回應 Bill Gates 2026-08-27 關於 AI 取代工作嘅警告 — 我哋嘅答案係「AI 幫人做得更好，而唔係取代人」。

## 五、應用場景建議（會議討論焦點）

### 短期 POC（1-3 個月）— 建議先做呢個
**📄 智能文書/研究自動化**（見效最快、風險最低）
- 輸入主題 → 自動研究 + 出報告（我哋已 demo）
- 企業應用：市場研究、競品分析、法規追蹤
- **Demo 流程：** 即場輸入主題 → 5-10 分鐘出完整報告連圖表

### 中期（3-6 個月）
**💬 智能客服/內部知識庫助手**
- 結合 RAG：公司文件 + 政策 → 員工/客戶即問即答
- 需要：向量資料庫 + 權限管理

### 長期（6-12 個月）
**🧠 決策支援 Agent**
- 多 Agent 模擬不同觀點（紅隊/藍隊）輔助決策
- 需要：更成熟嘅評估框架

## 六、道德設計（我哋嘅差異化優勢）

參考 `docs/道德設計原則.md`（fring1118 提供）：
1. **以人為本** — Agent 係增強工具，唔係取代者
2. **透明** — 每個輸出可追溯資料來源
3. **私隱** — 數據最小化 + 用戶控制
4. **問責** — 人類保留最終決定權

> 💡 **會議賣點：** 市面上大部分 Agent 產品主打「自動化取代人」，我哋主打「AI 增強人」— 呢個係企業客戶（尤其重視 ESG/合規嘅公司）會 buy 嘅角度。
