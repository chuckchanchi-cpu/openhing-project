## 🎯 首選應用場景：研究助手

**推薦指數**: ⭐⭐⭐⭐⭐ (5/5)  
**道德評分**: ⭐⭐⭐⭐ (4/5)

### 核心功能流程

```
用戶輸入研究主題
    ↓
[搜索 Agent] → 搜索文獻/資料
    ↓
[分析 Agent] → 閱讀、摘要、提取關鍵信息
    ↓
[整合 Agent] → 合併多個來源
    ↓
[寫作 Agent] → 撰寫結構化報告
    ↓
用戶審閱 + 修改
```

### 技術需求
- **框架**: CrewAI / AutoGen (等待技術調研確認)
- **LLM**: 長上下文 (128K+) 處理完整論文
- **APIs**: Serper API、學術數據庫 API
- **存儲**: 文獻數據庫、引用管理
