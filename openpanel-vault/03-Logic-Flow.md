# 03 — 決策邏輯：每 Round 嘅標準 Pipeline

```
1. 議題界定（Claw）
   └─ 確認問題 + 需要嘅數據角度
2. 數據搜集（Claw）
   └─ web search / 市場數據 → 核實數字 → 整「數據 brief」
3. 發 brief 畀三席（同一份）
   └─ 限定：只准用 brief 入面嘅數字，唔好亂編
4. 三席獨立輸出
   └─ 格式固定：立場一句 → 4-6 論點（≤350字）→ 三情境機率（標明估計）
      → 改變睇法條件（falsifiability）→ 一條挑戰問題
5. 交叉質詢（Claw 綜合）
   └─ 抄低互相挑戰嘅點 + 數據勘誤（例：Claude 糾正 -20.3% vs -21.8% 口徑）
6. 綜合報告（Claw）
   └─ 圖為主字為輔 PDF + 結論卡 → 發到 Openhing group
7. 🛑 HUMAN STOP
   └─ 等人類拍板，先繼續下一步
```

## 質量控制規則
1. **數字紀律**：席位只准用 brief 入面核實數據；Claw 綜合時再核對一次（Trial #2 Claude 曾捉到口徑錯誤 ✅）
2. **機率必須標明係估計**：唔可以扮事實
3. **falsifiability**：每個席位要講「乜嘢會令我改變睇法」
4. **挑戰問題**：每個席位要向其他席位出一條尖銳問題
5. **Human Stop 係硬規則**：agent 唔可以自己落最終決定

## 點樣判斷結論質素
- 三席共識 = 高信心訊號（三個唔同 brain 同向）
- 三席分歧 = 要人類裁決嘅位（例：炒人利好定利淡）
- 席位捉到對方錯誤 = 多 brain 嘅實際價值
