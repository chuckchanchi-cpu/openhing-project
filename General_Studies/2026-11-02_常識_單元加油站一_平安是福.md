## 📝 一、綜合：各種意外的處理方法

按處理方法的先後次序排列（A-I）：

**處理方法選項：**
- A. 用毛巾包着冰袋，冷敷受傷部位
- B. 用鑷子夾着藥棉，抹乾受傷部位
- C. 用消毒敷料蓋在傷口上
- D. 讓患者平躺在空氣流通的地方
- E. 用清水或消毒藥水清洗傷口
- F. 立即用冷水沖洗受傷部位
- G. 解開患者的衣領及膝帶
- H. 把受傷部位墊高
- I. 把患者的腿部略為抬高

**各種意外處理順序：**

| 意外 | 順序 |
|------|------|
| **1. 扭傷** | A → H → I（冰敷 → 墊高 → 抬高腿部） |
| **2. 燙傷** | F → E → C（冷水沖洗 → 清洗傷口 → 消毒敷料） |
| **3. 昏厥** | D → G → H（平躺通風 → 解開衣領 → 墊高） |
| **4. 擦傷** | B → E → C（抹乾 → 清洗 → 消毒膠布） |

## 📝 二、填充

1. 要定期檢查急救箱，確保沒有**過期**或**損壞**的用品。
2. 為患者進行急救，可以防止**傷勢惡化**或病情惡化，甚至挽救患者的**性命**。
3. 過馬路時，行人必須遵守**交通**規則，提高**警覺**，注意道路安全。
4. 我們不要**強行**急救拔服務，讓有需要的人得到及時救援。
5. 我們平日要留意所在的**環境**和**逃生路線**，在遇上火警時可以儘快逃生。

## 📝 三、生活情境：郊遊安全

**情景：** 爸爸、媽媽、家賢一家人去郊遊

### 1. 誰穿着不合適的衣服去郊遊？郊遊時應該穿甚麼衣服？
> 穿着不合適衣服：媽媽（可能穿着高跟鞋或深色不透氣衣服）
> 應該穿：淺色、寬鬆、透氣的運動衣服和運動鞋

### 2. 郊遊時遇到山火，我們應該怎樣做？
> 不要嘗試救火 → 立即遠離火場 → 往逆風方向逃生 → 撥打 999 求救

### 3. 下山後，媽媽出現熱衰竭，爸爸和家賢應該怎樣幫助她？
> 把媽媽移到陰涼通風的地方 → 解開衣領 → 用濕毛巾降溫 → 補充水分和鹽分 → 如情況嚴重，召喚救護車
