## 📝 一、簡單急救（p.2-3）

### 選擇：急救箱用品
急救箱內應存放：①藥品 ②剪刀 ③膠布 ④溫度計 ⑤手套 ⑥消毒藥水 ⑦紗布 ⑧棉花
（全部都係正確急救用品）

### 看圖判斷（避免意外 ✓／造成意外 ✗）
1. 電梯口嬉戲 → ✗
2. 跑住食嘢 → ✗
3. 濕手掂電器 → ✗
4. 圖加 ✗ 嘅行為可能引起：**手受傷／跌傷／觸電**

### 填充（答案）
1. 急救箱應放在**容易看見**和容易取用的位置，**過期**的急救用品要儘快更換。
2. 流鼻血時，用手捏住鼻骨下的**柔軟**部分，暫時用**口**呼吸。
3. 為扭傷的傷者**冰敷**患處，以減輕**痛楚**和**腫脹**。
4. 急救的目的是防止傷者的**傷勢惡化**。傷者情況嚴重，應立即就醫或召喚**救護車**送院。

### 配對（替傷者急救）
| 傷勢 | 處理方法 |
|------|---------|
| 擦傷/割傷 | D. 清水/消毒藥水沖洗傷口，貼消毒膠布 |
| 扭傷紅腫 | C. 檢查受傷部位，冷敷紅腫痛熱的部位 |
| 燒傷/燙傷 | B. 用冷水沖洗受傷部位 |
| 昏迷/休克 | A. 墊高雙腳，保持空氣流通 |

## 📝 二、自救和求救（p.4）

### 生活情境：火警自救（林太太）
**Q: 如果你是林太太，發現家中發生火警，你會怎樣做？**
答案：用濕毛巾掩住口鼻 → 伏低爬行 → 走樓梯逃生 → 到安全地方打 999 求救

**Q: 林太太可以怎樣避免火警發生？**
答案：出門前關掉電器和爐具、定期檢查電線、不超負荷用電

### 配對（意外預防）
| 做法 | 可避免的意外 |
|------|------------|
| 1. 燒烤後用水弄熄火種才離開 | B. 火災 |
| 2. 郊遊帶備足夠食水，定時補充 | D. 中暑 |
| 3. 郊遊不採摘野果/野菌進食 | D. 中毒 |
| 4. 穿淺色透氣運動衣服 | C. 熱衰竭 |
| 5. 定期檢查輸送氣體的喉管 | A. 氣體洩漏 |
| 6. 一個萬用插頭不接三四種電器 | B. 火災 |

### 選擇（答案）
1. 準備逃生的「逃生三寶」是：**手提滅火筒、手電筒、防煙面罩**
2. 正確使用道路的行為：**一邊聽歌一邊過馬路** ✗／留意路面情況 ✓
3. 提供救援服務的機構：**民安隊、醫療輔助隊、香港聖約翰救傷隊**
4. 召喚救護車的情況：**發生交通意外、煮食時被油濺傷手、有人昏迷不醒**

### 簡答（火警逃生三寶）
**Q: 火警逃生時應準備的「逃生三寶」是甚麼？**
答案：(1) 手提滅火筒 (2) 手電筒 (3) 防煙面罩

**Q: 遇到氣體洩漏意外，應該怎樣做？**
答案：(1) 關掉氣體閥門 (2) 打開窗戶通風 (3) 不要開燈/打電話 (4) 離開現場再求救

**Q: 舉出三個乘車時保障自己和他人安全的方法。**
答案：(1) 繫好安全帶 (2) 不將手伸出窗外 (3) 不在車廂內走動
